Business Sales Analysis

📌 Project Overview

This project analyzes business sales data to understand sales performance and identify important business insights using Excel and Power BI.

🎯 Objective

The main objective of this project is to analyze sales data and understand sales trends, product performance, and overall business performance.

🛠️ Tools Used

- Microsoft Excel
- Power BI

📊 Analysis Performed

- Sales Performance Analysis
- Product-wise Sales Analysis
- Category-wise Sales Analysis
- Regional Sales Analysis
- Monthly Sales Trend Analysis
- Profit Analysis

📈 Dashboard

An interactive Power BI dashboard was created to visualize key sales metrics and business performance using charts, KPIs, and filters.

💡 Key Insights

- Identified top-performing products and categories.
- Analyzed sales performance across different regions.
- Identified sales trends over time.
- Compared sales and profit performance.

📂 Project Files

- "Dataset" – Sales data used for the analysis
- "Excel" – Data cleaning and analysis
- "PowerBI" – Interactive Power BI dashboard
- "Dashboard" – Dashboard screenshots
